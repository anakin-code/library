3. Serviceでcontextごとに分ける

ContentService にこれを追加、または既存の searchedContentsResponse の中身をこれにする。

@Transactional(readOnly = true)
public Page<ContentShowResponseDto> searchContents(
        String q,
        String context,
        User loginUser,
        Pageable pageable
) {
    String keyword = normalizeKeyword(q);
    SearchTarget searchTarget = SearchTarget.from(context);

    Page<Content> contents = switch (searchTarget) {
        case CONTENT -> contentRepository.findByTitleKeyword(keyword, pageable);
        case USER -> contentRepository.findByUserNameKeyword(keyword, pageable);
        case TAG -> contentRepository.findByTagNameKeyword(keyword, pageable);
    };

    return contents.map(content -> toContentShowResponseDto(content, loginUser));
}

private String normalizeKeyword(String q) {
    if (q == null || q.isBlank()) {
        return "";
    }
    return q.trim();
}

ここで context 分岐をServiceに閉じ込める。
ControllerやRepositoryに分岐を散らさない。

4. SearchTarget enumを作る

service 配下でもいいけど、検索用なので例えばここ。

service/search/SearchTarget.java
package simplex.pj148.skippy.server.service.search;

import simplex.pj148.skippy.server.exception.BusinessException;
import org.springframework.http.HttpStatus;

public enum SearchTarget {
    CONTENT("content"),
    USER("user"),
    TAG("tag");

    private final String value;

    SearchTarget(String value) {
        this.value = value;
    }

    public static SearchTarget from(String context) {
        if (context == null || context.isBlank()) {
            throw new BusinessException("INVALID_SEARCH_CONTEXT", HttpStatus.BAD_REQUEST);
        }

        for (SearchTarget target : values()) {
            if (target.value.equalsIgnoreCase(context.trim())) {
                return target;
            }
        }

        throw new BusinessException("INVALID_SEARCH_CONTEXT", HttpStatus.BAD_REQUEST);
    }
}

ただ、あなたの BusinessException は protected コンストラクタっぽかったので、そのままだと new BusinessException(...) できない可能性がある。
その場合は専用例外を作る。

7. Service全体の完成形
package simplex.pj148.skippy.server.service;

import lombok.RequiredArgsConstructor;
import org.springframework.data.domain.Page;
import org.springframework.data.domain.Pageable;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import simplex.pj148.skippy.server.controller.dto.response.ContentShowResponseDto;
import simplex.pj148.skippy.server.entity.Content;
import simplex.pj148.skippy.server.entity.User;
import simplex.pj148.skippy.server.repository.ContentRepository;
import simplex.pj148.skippy.server.service.search.SearchTarget;

@Service
@RequiredArgsConstructor
public class ContentService {

    private final ContentRepository contentRepository;

    @Transactional(readOnly = true)
    public Page<ContentShowResponseDto> searchContents(
            String q,
            String context,
            User loginUser,
            Pageable pageable
    ) {
        String keyword = normalizeKeyword(q);
        SearchTarget searchTarget = SearchTarget.from(context);

        Page<Content> contents = switch (searchTarget) {
            case CONTENT -> contentRepository.findByTitleKeyword(keyword, pageable);
            case USER -> contentRepository.findByUserNameKeyword(keyword, pageable);
            case TAG -> contentRepository.findByTagNameKeyword(keyword, pageable);
        };

        return contents.map(content -> toContentShowResponseDto(content, loginUser));
    }

    private String normalizeKeyword(String q) {
        if (q == null || q.isBlank()) {
            return "";
        }
        return q.trim();
    }

    private ContentShowResponseDto toContentShowResponseDto(Content content, User loginUser) {
        return ContentShowResponseDto.builder()
                .contentsId(content.getContentsId())
                .userId(content.getUser().getUserId())
                .userName(content.getUser().getName())
                .title(content.getTitle())
                .recommend(content.getRecommend())
                .contentsBody(content.getContentsBody())
                .categoryId(content.getCategory().getCategoryId())
                .categoryName(content.getCategory().getCategoryName())
                .editFlg(content.getUser().getUserId().equals(loginUser.getUserId()))
                .build();
    }
}

ただし、toContentShowResponseDto は既存の変換処理があるなら、それを使う方がいい。
同じ変換処理を複数箇所に書くと、17人開発でズレる。
