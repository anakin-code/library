
NeedList.tsx の絞り込み部分をこう変える

Select / MenuItem で作っている

<FormControl>
  <Select>
    ...
  </Select>
</FormControl>

を、以下の Autocomplete に置き換える。

1. import に Autocomplete を追加
import {
  Alert,
  Autocomplete,
  Box,
  Button,
  CircularProgress,
  FormControl,
  Grid,
  MenuItem,
  Modal,
  Pagination,
  Select,

  Typography,

ただし、下のコードに置き換えるなら、絞り込みでは FormControl, Select, MenuItem は不要になる。
ソート順で Select を使っているなら残してOK。

2. 型は今のままでOK

君の NeedList.tsx にあるこれを使う。

type Affiliated = {
  affiliatedId: number;
  affiliatedName: string;
};

type Rank = {
  rankId: number;
  rankName: string;
};

type Category = {
  categoryId: number;
  categoryName: string;
};
3. 選択中の値を取得する変数を追加

return の前あたりにこれを追加。

const selectedAffiliated =
  affiliatedList.find(
    (affiliated) => String(affiliated.affiliatedId) === affiliatedId
  ) ?? null;

const selectedPosition =
  rankList.find((rank) => String(rank.rankId) === positionId) ?? null;

const selectedCategory =
  categoryList.find(
    (category) => String(category.categoryId) === categoryId
  ) ?? null;

今の state がこういう形ならそのまま使える。

const [affiliatedId, setAffiliatedId] = useState<string>("");
const [positionId, setPositionId] = useState<string>("");
const [categoryId, setCategoryId] = useState<string>("");
