スキル削除条件

そのスキルを使っている社員が 0人
または
使っている社員が自分1人だけ

つまり、単純に CareerSkill の件数ではなく、そのSkillを使っているProfileの人数で判定する。

1. Repository追加

CareerSkillRepository.java

@Query("""
    SELECT COUNT(DISTINCT c.profile.hrid)
    FROM CareerSkill cs
    JOIN cs.career c
    WHERE cs.skill.skillId = :skillId
""")
long countDistinctProfilesBySkillId(@Param("skillId") Long skillId);

@Query("""
    SELECT COUNT(DISTINCT c.profile.hrid)
    FROM CareerSkill cs
    JOIN cs.career c
    WHERE cs.skill.skillId = :skillId
      AND c.profile.hrid <> :hrid
""")
long countOtherProfilesBySkillId(
        @Param("skillId") Long skillId,
        @Param("hrid") String hrid
);
2. Service追加

SkillService.java

@Transactional
public void deleteSkill(Long skillId, String loginHrid) {
    Skill skill = skillRepository.findById(skillId)
            .orElseThrow(() -> new IllegalArgumentException("スキルが見つかりません。"));

    long otherUserCount =
            careerSkillRepository.countOtherProfilesBySkillId(skillId, loginHrid);

    if (otherUserCount > 0) {
        throw new IllegalArgumentException(
                "他のユーザーが使用しているスキルのため削除できません。"
        );
    }

    careerSkillRepository.deleteBySkillSkillId(skillId);

    skillRepository.delete(skill);
}
3. CareerSkillRepositoryに削除処理追加
void deleteBySkillSkillId(Long skillId);

これで、自分だけが使っている場合は先に career_skill を消してから、skill を消せる。

4. Controller追加

SkillController.java

@DeleteMapping("/{skillId}")
public ResponseEntity<Void> deleteSkill(
        @PathVariable Long skillId,
        @RequestParam String hrid
) {
    skillService.deleteSkill(skillId, hrid);
    return ResponseEntity.noContent().build();
}

重要ポイント

CareerSkill の件数で見るとダメ。

例えば自分が同じスキルを3つのCareerで使っていたら、

CareerSkill件数 = 3

になる。

でも使っている人は自分1人だけ。

だから見るべきなのは、

COUNT(DISTINCT profile.hrid)

これ。

この設計なら、
未使用スキルは削除OK、
自分だけ使用中も削除OK、
他人が使っていたら削除NG。
