
1. 入力した瞬間に選択解除

入力欄の onChange はこれ。

onChange={(e) => {
    setDeleteSkillKeyword(e.target.value);
    setDeleteSkillId(""); // 手入力したら未選択に戻す
}}

これで、候補をクリックしない限り削除できない。

2. 候補クリック時だけ skillId を入れる
onClick={() => {
    setDeleteSkillId(String(skill.skillId));
    setDeleteSkillKeyword(skill.skillName);
}}
3. 削除ボタンを候補選択必須にする
<button
    type="button"
    onClick={handleDeleteSkill}
    disabled={!deleteSkillId || isDeletingSkill}
    className={`
        rounded-lg px-4 py-2 font-semibold text-white
        ${
            deleteSkillId && !isDeletingSkill
                ? "bg-red-600 hover:bg-red-700"
                : "bg-gray-400 cursor-not-allowed"
        }
    `}
>
    {isDeletingSkill ? "削除中..." : "DBから削除"}
</button>
4. handleDeleteSkill の失敗時にモーダルを閉じる

catch の最後でこれを入れる。

setIsSkillDeleteModalOpen(false);
setDeleteSkillId("");
setDeleteSkillKeyword("");

完成形はここ。

} catch (error: unknown) {
    if (axios.isAxiosError(error)) {
        const errorData = error.response?.data;

        if (typeof errorData === "string") {
            setErrorMessage(errorData);
        } else if (
            typeof errorData === "object" &&
            errorData !== null &&
            "message" in errorData
        ) {
            setErrorMessage(
                String((errorData as { message?: string }).message)
            );
        } else {
            setErrorMessage("スキルの削除に失敗しました。");
        }
    } else {
        setErrorMessage("スキルの削除に失敗しました。");
    }

    // ===== 削除失敗時もモーダルを閉じる =====
    setIsSkillDeleteModalOpen(false);
    setDeleteSkillId("");
    setDeleteSkillKeyword("");
} finally {
    setIsDeletingSkill(false);
}
5. handleDeleteSkill の最初も候補選択必須にする
if (!deleteSkillId) {
    setErrorMessage("候補から削除するスキルを選択してください。");
    return;
}
