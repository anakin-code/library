useApi()の中に共通関数を追加

この直後、

export function useApi() {
  const auth: AuthContextProps = useAuth();

に、次を追加する。

  const checkAccountBanned = useCallback(
    async (response: Response): Promise<Response> => {
      if (response.status !== 403) {
        return response;
      }

      try {
        const errorData: {
          code?: string;
          message?: string;
        } = await response.clone().json();

        if (errorData.code !== "ACCOUNT_BANNED") {
          return response;
        }

        sessionStorage.setItem(
          "loginErrorMessage",
          errorData.message ?? "このアカウントは利用停止されています"
        );

        // react-oidc-contextのローカル認証情報を削除
        await auth.removeUser();

        window.location.href = "/";
      } catch (error) {
        console.error("アカウント停止情報の取得に失敗しました", error);
      }

      return response;
    },
    [auth]
  );

Cognitoログイン画面まで戻したい場合は、プロジェクトの既存ログアウト処理に合わせて、

await auth.signoutRedirect();

を使う形でもいい。ただし、すでにヘッダーなどにログアウト機能があるなら、そこで使っている処理と同じものに合わせる。

2. fetchを修正

今はこうなっている。

const fetch = useCallback(
  (path: ApiPath, options: UseApiFetchOptions = {}) => {
    return apiFetch(path, {
      ...options,
      accessToken: auth.user?.access_token,
    });
  },
  [auth.user?.access_token],
);

これを次に置き換える。

const fetch = useCallback(
  async (
    path: ApiPath,
    options: UseApiFetchOptions = {}
  ): Promise<Response> => {
    const response = await apiFetch(path, {
      ...options,
      accessToken: auth.user?.access_token,
    });

    return checkAccountBanned(response);
  },
  [auth.user?.access_token, checkAccountBanned],
);

変更点は、

return apiFetch(...)

を、

const response = await apiFetch(...);

return checkAccountBanned(response);

にしたこと。

今はこう。

これを次に置き換える。

const sendJson = useCallback(

修正後のuseApi全体
export function useApi() {
  const auth: AuthContextProps = useAuth();

  const checkAccountBanned = useCallback(
    async (response: Response): Promise<Response> => {
      if (response.status !== 403) {
        return response;
      }

      try {
        const errorData: {
          code?: string;
          message?: string;
        } = await response.clone().json();

        if (errorData.code !== "ACCOUNT_BANNED") {
          return response;
        }

        sessionStorage.setItem(
          "loginErrorMessage",
          errorData.message ?? "このアカウントは利用停止されています"
        );

        await auth.removeUser();

        window.location.href = "/";
      } catch (error) {
        console.error("アカウント停止情報の取得に失敗しました", error);
      }

      return response;
    },
    [auth]
  );

  const fetch = useCallback(
    async (
      path: ApiPath,
      options: UseApiFetchOptions = {}
    ): Promise<Response> => {
      const response = await apiFetch(path, {
        ...options,
        accessToken: auth.user?.access_token,
      });

      return checkAccountBanned(response);
    },
    [auth.user?.access_token, checkAccountBanned],
  );

  const sendJson = useCallback(
    async <TBody>(
      path: ApiPath,
      body: TBody,
      options: UseApiFetchOptions = {}
    ): Promise<Response> => {
      const response = await apiSendJson(path, body, {
        ...options,
        accessToken: auth.user?.access_token,
      });

      return checkAccountBanned(response);
    },
    [auth.user?.access_token, checkAccountBanned],
  );

  return {
    /** ボディなしでHTTPリクエストを送信するときに利用します */
    fetch,

    /** ボディつきでHTTPリクエストを送信するときに利用します */
    sendJson,
  };
}
大事な点

apiSendJson()は内部で既に、

return apiFetch(path, ...)

を呼んでいる。ただ、apiFetchはuseApiの外にあるため、そこでは直接、

auth.removeUser()

を使えない。

そのため今回は、

apiFetch自体は今のまま
useApiのfetchとsendJsonで返却結果を確認

という修正でいい。

また、サーバーから本当に次の形式が返る必要がある。

{
  "code": "ACCOUNT_BANNED",
  "message": "このアカウントは利用停止されています"
}

サーバーがmessageしか返していないなら、今のクライアントの

errorData.code !== "ACCOUNT_BANNED"

では判定できない。そこはサーバー側のGlobalExceptionHandlerのレスポンス形式と揃える必要がある。
