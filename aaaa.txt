2. ProjectService でチェック

ProjectService.java のプロジェクト内容更新メソッドに追加。

例えば今こういうメソッドがあるなら、

public ProjectResponse updateProject(Long projectId, ProjectRequest request) {
    Project project = projectRepository.findById(projectId)
            .orElseThrow(() -> new IllegalArgumentException("プロジェクトが見つかりません。"));

    project.setProjectName(request.getProjectName());
    project.setProjectContent(request.getProjectContent());

    return convertToResponse(projectRepository.save(project));
}

これをこうする。

public ProjectResponse updateProject(
        Long projectId,
        ProjectRequest request,
        String hrid
) {
    Project project = projectRepository.findById(projectId)
            .orElseThrow(() -> new IllegalArgumentException("プロジェクトが見つかりません。"));

    boolean isCurrentMember =
            careerRepository.existsByProfileHridAndProjectProjectIdAndEndTimeIsNull(
                    hrid,
                    projectId
            );

    if (!isCurrentMember) {
        throw new IllegalArgumentException("現在このプロジェクトに所属していないため、プロジェクト内容を編集できません。");
    }

    project.setProjectName(request.getProjectName());
    project.setProjectContent(request.getProjectContent());

    return convertToResponse(projectRepository.save(project));
}

ProjectService に CareerRepository を注入する。

private final CareerRepository careerRepository;

public ProjectService(
        ProjectRepository projectRepository,
        DivisionRepository divisionRepository,
        CareerRepository careerRepository
) {
    this.projectRepository = projectRepository;
    this.divisionRepository = divisionRepository;
    this.careerRepository = careerRepository;
}
3. ProjectController で hrid を受け取る

今の更新APIがこうなら、

@PutMapping("/{id}")
public ProjectResponse updateProject(
        @PathVariable Long id,
        @RequestBody ProjectRequest request
) {
    return projectService.updateProject(id, request);
}

こう変える。

@PutMapping("/{id}")
public ProjectResponse updateProject(
        @PathVariable Long id,
        @RequestParam String hrid,
        @RequestBody ProjectRequest request
) {
    return projectService.updateProject(id, request, hrid);
}
