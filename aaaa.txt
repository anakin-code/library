
1つ目、rankdir: "LR" だから横に広がってはみ出る。
2つ目、線の太さを normalizedWeight で出してるけど、値が似てるから太さもほぼ同じ。

こう直して。

1. dagre設定を変更
graph.setGraph({
  rankdir: "TB",
  ranksep: 80,
  nodesep: 70,
  marginx: 40,
  marginy: 40,
});

LR ではなく TB。横長ではなく縦方向に整理する。

2. エッジの太さを totalMonths 基準にする

rawEdges をこれに変更。

const rawEdges: Edge[] = useMemo(() => {
  const maxEdgeMonths = data.edges
    .map((edge) => edge.totalMonths)
    .reduce((max, months) => Math.max(max, months), 1);

  return data.edges.map((edge) => {
    const weightRate = edge.totalMonths / maxEdgeMonths;

    return {
      id: `${edge.source}-${edge.target}`,
      source: String(edge.source),
      target: String(edge.target),
      type: "straight",
      label: formatPeriod(edge.years, edge.months),
      style: {
        stroke: "#334155",
        strokeWidth: 1 + weightRate * 8,
      },
      labelStyle: {
        fontSize: 11,
        fontWeight: 600,
        fill: "#222",
      },
    };
  });
}, [data]);

これで、

7年 → 太い
5年1ヶ月 → 中太
1年11ヶ月 → 細め

みたいに差が出る。
