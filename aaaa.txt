const response: Response = await api.fetch(requestUrl);

ここで requestUrl の型がただの string になっている。
でも、君の useApi の fetch はたぶん型がこうなってる。

fetch(path: `/${string}`, options?: RequestInit)

つまり、api.fetch() は 必ず / から始まる文字列 を要求している。

でも requestUrl は中身としては

"/api/needs/search?..."

でも、TypeScript上はただの string だから怒られてる。

エラーの意味はこれ。

Argument of type 'string' is not assignable to parameter of type `/${string}`

つまり、

中身は /api/... っぽいけど、型としてはただのstringだから信用できない

ということ。

修正方法

requestUrl の型を /${string} にする。

今こうなってるはず。

const requestUrl: string = useMemo((): string => {
  const params = new URLSearchParams();

  params.append("page", String(page));
  params.append("size", "18");
  params.append("orderBy", orderBy);

  if (appliedKeyword.trim() !== "") {
    params.append("keyword", appliedKeyword.trim());
  }

  if (affiliatedId !== "") {
    params.append("affiliatedId", affiliatedId);
  }

  if (positionId !== "") {
    params.append("positionId", positionId);
  }

  if (categoryId !== "") {
    params.append("categoryId", categoryId);
  }

  return `/api/needs/search?${params.toString()}`;
}, [page, orderBy, appliedKeyword, affiliatedId, positionId, categoryId]);

これをこう直す。

const requestUrl = useMemo((): `/${string}` => {
  const params = new URLSearchParams();

  params.append("page", String(page));
  params.append("size", "18");
  params.append("orderBy", orderBy);

  if (appliedKeyword.trim() !== "") {
    params.append("keyword", appliedKeyword.trim());
  }

  if (affiliatedId !== "") {
    params.append("affiliatedId", affiliatedId);
  }

  if (positionId !== "") {
    params.append("positionId", positionId);
  }

  if (categoryId !== "") {
    params.append("categoryId", categoryId);
  }

  return `/api/needs/search?${params.toString()}`;
}, [page, orderBy, appliedKeyword, affiliatedId, positionId, categoryId]);

これで

await api.fetch(requestUrl);

が通る。

さらに短く直すなら

この1行だけでもいける。

const response: Response = await api.fetch(requestUrl as `/${string}`);

ただ、これは応急処置。
ちゃんと直すなら、requestUrl の戻り値型を /${string} にする方がきれい。

もう1つのエラー

写真にこれも出てる。

selectedAffiliated is assigned a value but never used

これは、上で

const selectedAffiliated = ...

を作ったのに、JSX側でまだ使ってないという意味。

つまり、Autocomplete に置き換えていないか、置き換えたけど value={selectedAffiliated} を書いてない。

使うならこう。

<Autocomplete
  disablePortal
  size="small"
  options={affiliatedList}
  value={selectedAffiliated}
  getOptionLabel={(option: Affiliated): string => option.affiliatedName}
  isOptionEqualToValue={(option, value): boolean =>
    option.affiliatedId === value.affiliatedId
  }
  onChange={(_, value: Affiliated | null): void => {
    setAffiliatedId(value ? String(value.affiliatedId) : "");
    setPage(0);
  }}
  renderInput={(params) => (
    <TextField {...params} placeholder="指定なし" />
  )}
/>

使わないなら、selectedAffiliated 自体を消す。
